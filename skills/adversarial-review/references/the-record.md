# Ending the review

**Loaded when** you are closing a review: writing its final report (`../references/report-template.md`), appending its row to the review index (`../references/index-row-template.md`) — **or writing the dispatches whose output the report reads**, which is a job before the terminal ruling that needs this file.

The holder authors the final report and sends its draft through the `engagement` cell's **Source-verification rule** before posting it, supplying dependent record content only after the posted report gives it a source URL. A report carrying an external-pass receipt is posted to the linked work issue, never the reviewed pull request's issue thread, so posting the account does not move its own source.

**The report reads each field from its producer** — a seat's raw count and the revision and tree each recipient worked at are asked for in the dispatch (`../references/dispatch.md`), each high's finders are credited at the merge (`../references/arbitration.md`), and what the review cost is captured from each dispatch's return as it arrives. **A field nobody asked for is silently empty here**, and reads exactly like a field that had nothing to say.

The final report is the review's whole evidence to a reader who was not in it, posted to the review's chosen issue. Per-seat counts are credits — a seat's `high` counts the sustained highs it is credited on, never distinct highs [D-185] — and the unit counted throughout is the finding as originated and dispositioned, never a row of a ruling table. Every value the index row carries has a prior statement here to be read against, which is what makes the row checkable at all.

**The split by consequence shape is what makes drift legible.** A review whose sustained findings were mostly apparatus-facing spent its round on the record of having reviewed rather than on the work — a fact about the instrument, which the next lane choice reads and which a count of findings cannot show.

Where the repo keeps a review index, append **one row per review, whatever it took to run**, written once and never maintained. **The row carries no arithmetic over the findings** — every count it used to carry was totalled and reconciled by hand into a file nobody may edit, and that is this index's whole defect record — so what a review was worth is read from the report it links, and how many highs it sustained is the length of the list. **A fact about the run is not that arithmetic**: who staffed it is one, and what the review cost to run is another where a repository records it, read off what each dispatch returned rather than totalled from a transcript, evidence for the choice `../references/the-shape.md` makes. **A repository recording it says in its own material which dispatches it counts**: two records counting different populations cannot be read against each other, and the span is not obvious — whether the review's own cold pass, a post-fix experience session, or a tool the session invoked itself sits inside it is a choice each time.

Before reading what an index says, ask what it could have said: an evidence loop whose instrument cannot express the finding it tests for is not evidence, and a record is silent about everything its fields do not carry. **A convention stated per row is one no later row inherits**, which is why the row's spellings are stated once, in the template, and not in a row. Where the repo keeps no index, the report alone is the record.

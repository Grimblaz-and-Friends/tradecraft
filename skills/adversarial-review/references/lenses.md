# Closing a recurring class

**Loaded when** the same defect class has returned — across findings, reviews, or repositories — or a standing instruction to look may have outlived the class it finds. A seat working the lens brief it was handed does not need it.

When the same defect class returns — across findings, reviews, or repos — the fix is never another seat: it is a **promoted lens**, worded so it would have caught the class's own motivating exemplar, carried in this cell's evidence standards, wherever in the cell they sit, or a seat's brief. Seats catch instances; lenses retire classes.

**A lens retires on either of two grounds**: the class it finds is repeatedly not worth acting on, or a mechanism now catches it. **What retires is any standing instruction to look** — a seat's brief, a lens in this cell's evidence standards, wherever they sit, a scope clause naming a target — and not only a lens promoted above. A finding costs from the moment it exists, so a class nobody will act on is stopped at the brief and never at the ruling. The report names any retirement and the evidence that earned it.

# After a fix batch — re-validation, and the external pass

**Loaded when** a fix batch has landed and its look is owed, or a pull request is open and an automated reviewer may have posted on it. A first cycle's seats, defense and judge do not need it.

## Post-fix re-validation — mandatory, executable, fix-wide

Fixes are a defect source comparable to fresh diffs, and the repair that reproduces the class it closes is what this look most often finds. Run everything that runs — suites, lint, and the findings' own probes re-derived against the fixed tree. Scope to everything the fix touched, the review's own bookkeeping included: the merged finding list, the report, the commit message, and the PR body. **That scope is a bound as well as a floor: the look reads the fix diff, whatever depends on it, and each sustained high's territory — not the artifact over again** — a pass re-reading what the panel already read is a second panel bought at a cycle's price, and it finds what a fresh pass on any tree finds. *Whatever depends on it* is the widest of the three and the one a literal reading drops: a fix that moves a definition, a contract, or a term of art reaches every sentence turning on it, whose characters never changed — the failure the `revision-diff` seat (`../references/roster.md`) exists to catch, which a diff-shaped bound would hand back. A look that reads only the diff has not discharged this floor. **Two conditions end the cycle and either is enough**: the count terminus stated in this paragraph, and the **relevance terminus** (`../references/the-record.md`) — a cycle whose look returns only apparatus-facing material has finished whatever the budget still allows. Which shape a finding has is read from the site it cites, by the rule in the merge's own file (`../references/arbitration.md`), and a finding citing sites of both kinds is artifact-facing. Post the report before writing the index row that cites it. **Every fix batch but the one a terminating ruling orders gets at least one prosecution look, plus defense on anything it finds — ruled by the review's terminal stage — and that floor is never priced or routed away.** That cycle ends when a look sustains **no high it will fix whose remedy changes the artifact** — the next-pass default (`../references/the-record.md`), narrowed to this cycle; a finding whose remedy is not a change to the artifact is recorded, never a further round. Until then the cycle continues without asking, so round one's ruling names the cycle budget, and exceeding it puts the review to the owner in that cycle's ruling rather than ending it.

## The external pass — reconciled every time

Automated reviewers configured on the repository post on a PR without being asked, so publishing before the panel makes their pass concurrent rather than serial. Reconcile after the terminal stage and before the fix batch; reconcile again if a push triggered a re-review, which reads the fixes and so checks the fix batch independently of the post-fix look above. Every comment gets a disposition: duplicate of an internal finding (named as such), sustained and fixed, sustained and routed with the vehicle, sustained and priced out with the price, or dropped on the evidence with a one-line reason. **Sustain on independent grounds or not at all** — an external reviewer's cited rule may not be one this repo runs; where the repo's own convention contradicts it, the convention wins and the drop says so. Record that the pass ran even when it produced nothing, and treat what actually posted as the input, never the roster — configured reviewers stub, rate-limit, and skip.

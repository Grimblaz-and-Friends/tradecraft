# After a fix batch — re-validation, the external pass, and the commissioned one

**Loaded when** a fix batch has landed and its look is owed, a pull request is open and an automated reviewer may have posted on it, or you invoked a review tool yourself. A first cycle's seats, defense and judge do not need it.

## Post-fix re-validation — mandatory, executable, fix-wide

Fixes are a defect source comparable to fresh diffs, and the repair that reproduces the class it closes is what this look most often finds. Run everything that runs — suites, lint, and the findings' own probes re-derived against the fixed tree. Scope to everything the fix touched. **Neither record is among the targets** — the review's own, the merged finding list and the report; and the change's own, the commit message and the PR body: prosecuting the record of having reviewed, or of having changed, is a retired lens, and a look that returns either has drifted rather than yielded. **Read as input is not read as subject**: the merged finding list is what locates each sustained high's territory, and consulting it for that is the look doing its job. **That scope is a bound as well as a floor: the look reads the fix diff, whatever depends on it, and each sustained high's territory — not the artifact over again** — a pass re-reading what the panel already read is a second panel bought at a cycle's price, and it finds what a fresh pass on any tree finds. *Whatever depends on it* is the widest of the three and the one a literal reading drops: a fix that moves a definition, a contract, or a term of art reaches every sentence turning on it, whose characters never changed — the failure the `revision-diff` seat (`../references/roster.md`) exists to catch, which a diff-shaped bound would hand back. A look that reads only the diff has not discharged this floor. **Two conditions end the cycle and either is enough**: the count terminus stated in this paragraph, and the **relevance terminus** (`../references/the-record.md`) — a cycle whose look returns only apparatus-facing material has finished whatever the budget still allows. Which shape a finding has is read from the site it cites, by the rule in the merge's own file (`../references/arbitration.md`), and a finding citing sites of both kinds is artifact-facing. Post the report before writing the index row that cites it. **Every fix batch but the one a terminating ruling orders gets at least one prosecution look, plus defense on anything it finds — ruled by the review's terminal stage — and that floor is never recorded or handed on in place of being run.** That cycle ends when a look sustains **no high it will fix whose remedy changes the artifact** — the next-pass default (`../references/the-record.md`), narrowed to this cycle; a finding whose remedy is not a change to the artifact is dispositioned where it stands, never a further round. Until then the cycle continues without asking, so round one's ruling names the cycle budget, and exceeding it puts the review to the owner in that cycle's ruling rather than ending it. **The batch re-derives every figure it invalidates, on every surface it wrote** — the commit message, the pull request body, a decision entry not yet merged. A fix moves the tree the figures were taken from, and no look now re-reads the change's own record, so the duty sits on the writer rather than on a cycle bought to catch it.

## The external pass — reconciled every time

**An external pass is what automation configured on the repository posts on the pull request without being asked**, which is why publishing before the panel makes it concurrent rather than serial. Reconcile after the terminal stage and before the fix batch; reconcile again if a push triggered a re-review, which reads the fixes and so checks the fix batch independently of the post-fix look above. Every comment gets a disposition: duplicate of an internal finding (named as such), sustained and fixed, sustained and handed on with its destination, sustained and recorded, or dropped on the evidence with a one-line reason. **Sustain on independent grounds or not at all** — an external reviewer's cited rule may not be one this repo runs; where the repo's own convention contradicts it, the convention wins and the drop says so. Record what actually posted even when it produced nothing; configured reviewers stub, rate-limit, and skip. Where the repository keeps an index, book that qualitative outcome as a non-empty string under top-level `external`, never as arithmetic and never under `seats`.

**A review tool the session invokes itself is a commissioned pass, not an external one.** It is asked for, no push triggers it, and none of the availability states above can apply to it, so the paragraph above does not govern it. It is not a seat either: invoking a tool supplies neither the cold boundary, nor the shared block, nor a lens brief, and who invoked it is not what makes a seat. Its findings **are a member of the terminal stage's docket** (`../references/arbitration.md`), whose enumeration is set by rule and reaches this one, and the report records what was run, what it returned, and each disposition. **It runs before that stage, where an external pass reconciles after it** — the inversion is the point: a pass you commissioned is evidence you chose to gather, and evidence arrives before the ruling it informs. It is never booked under `seats` or in the index's `external`, both of which would misdescribe its provenance.

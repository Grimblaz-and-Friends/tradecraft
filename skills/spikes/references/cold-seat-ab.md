# Cold-seat A/B, for a premise about what a reader does

**Loaded when** you are running a spike whose premise is about what a reader does under a wording — designing the arms, building the docket and the planted control, writing the dispatch, or reading what came back. A premise about what is in the material, or about whether a mechanism fires, does not need it: the cell body carries when a spike fires, the bound and the report every one takes, and that a spike commits nothing.

Where the executor is a reader, the run you need is a fresh session. Six properties, and each is what keeps the result evidence rather than one more opinion:

- **Fresh dispatches**, cold as the `engagement` cell defines it.
- **No repo history** — no issues, no decision log, no git; only the shipped material a real consumer would arrive with. Building such a tree is the `experience-session` cell's procedure, which covers one; an A/B needs one per arm.
- **A realistic docket**, written out: the situations the wording has to sort. A seat asked to discuss a sentence discusses it; a seat asked to work a docket executes it. **Where the rule under test opens only for a particular actor, the docket has to put a seat in that position**: a docket no seat can enter through the rule's own door tests the rule's absence, and both arms then agree for the reason that the rule never fired. **Each item is a near-miss**: the text under test has to be a live candidate for it, never the obvious answer — and where the arms hold two wordings, of **both**, an item obvious under one and a near miss under the other separating the arms by construction rather than by measurement. And **where that text is an exclusion, no item may be a job whose own positive trigger is named either by the excluding cell or by the cell the item should reach** — such an item arrives at a trigger of its own, every seat routes the same way in both arms, and a clause that works reads dead.
- **A planted control, placed in the material.** Text invented for the run and never landed, carried in what the arms hold rather than added to the docket, built to the same near-miss shape as the real items, so that a seat citing it shows the run could read a signal of that shape at all. A control pitched easier than the measurements passes while they stay blind. **And it must not be a second route to the behaviour the text under test produces** — a property of the plant against this run's docket and this text, never of the plant alone, and separate from the shape above: shape is difficulty calibration, this is what the plant licenses. A plant that independently licenses the action being measured makes the measured text dispensable wherever the plant rides, so no arm carrying it can show the text was reached for — and neither the gate below nor its seat-by-seat reading can see that, each reading a plant that was duly cited. **Where it rides follows the run's shape.** Where the ablated arm strips a whole class of text at once, the plant is built as a member of that class and goes with it, riding in the intact arm alone — and such a run **screens**: its result is attributable to the class rather than to any one sentence in it, so it licenses no deletion. Where only the text under test is removed — such a run **confirms** — the plant rides unchanged in both arms, which is what keeps the arms differing in exactly that text. Where neither arm is stripped and each holds a different wording of the text under test — such a run **substitutes** — the plant rides unchanged in both, as it does in a confirm. **A candidate that drops a clause removes it**, whatever else it rewords, so that run is a confirm on the dropped clause and answers to the deletion rule rather than to this shape's default.
- **Arms differing in exactly the sentence under test** — or, in a screen, in exactly the class under test; in a substitution, in which wording that sentence carries — and there the designer states, before dispatching, what substance one wording carries and the other does not — **where there is any**, that being what a seat can cite discriminatingly. A pair sharing all of it is still dispatchable and is read by arm attribution instead, on the second measure the scoring rules carry. Anything else that moves between arms is a second variable, and the result stops being attributable to the wording.
- **A docket that stops where the measurement is taken.** Ask for the seat's plan before it executes — every step, its reason, and the text it relied on — and stop it there. What you are measuring sits inside that plan among everything else, so the stop leads nothing where naming the step to stop at would, and the datum arrives in minutes rather than in the hours a real job takes ([#305](https://github.com/Grimblaz-and-Friends/tradecraft/issues/305)). It reaches a decision the seat takes before it acts, which is a stated intention rather than conduct; where the datum is visible only in what a run does, the run continues.

**Every bound in this cell is yours to impose on the seat, because it cannot infer one.** It does not know it is in a spike — that is the point — so the stop above and the disposal rule the cell body states reach it only by being written into its dispatch, along with the one bound it has no other source for: that it dispatches nothing of its own. A seat handed an ordinary job does what the repository says that job takes, recursively, and [five commissioned to settle one question ran the practice's whole flow](https://github.com/Grimblaz-and-Friends/tradecraft/issues/305), one of them dispatching its own.

**Ask what the seat would do before asking what the rule says.** The label a seat puts on a situation is the cheap measurement; what it reaches for unprompted is the one that transfers — and where the two disagree, what it reached for unprompted is the finding. **Then force a verdict on every candidate route, so that a silence is evidence**, the routes being whatever set the dispatch names — a run that leaves the set to the seat cannot be compared with the next one. A seat asked only what it would do never mentions what it declined, and on a near-miss a correct route needs no mention of the text under test at all. The forced walk comes after the unprompted question — asked first it hands the seat the label and contaminates it — and its compliance certifies nothing on its own, since a walk requiring a reasoned verdict on everything cannot return the negative. [The worked exemplar](https://github.com/Grimblaz-and-Friends/tradecraft/issues/115#issuecomment-5384143581) carries the docket, the arms, and what came back from each.

**Read the plant before you read a silence, in every arm whose silence you are reading.** Where the arms agreed and no seat in such an arm cited the plant, the run is **void** and licenses nothing: that arm has not shown it could detect a signal of that shape, so its silence says nothing. **Which arms that reaches follows where the plant rides**, by the planted-control rule above. In a confirm it rides in both, so both are read, and an ablated arm that cited nothing at all — neither the plant nor the text — voids the run as surely as a silent intact one; the standard a confirm certifies is a both-arms null, and an arm nobody has shown could read supplies no half of one. In a screen it rides with the ablated class, so the intact arm is the only one carrying it and the only one read. In a substitution neither arm is ablated and it rides in both, so both are read: an arm that cited nothing at all has not shown it could read a signal of that shape, whichever wording it held, and voids the run as an ablated arm's silence does. A run whose arms separated in what the seats **cited about the text under test** has no silence to read and stands on what it returned — arms separating only in what the seats *did* have not, the measure being the warrant a seat gave rather than the route it took, so such a run is still scored on its citations. **Read it seat by seat as well as arm by arm.** Where every arm carrying the plant has the same seats citing the plant as citing the text under test, an arm-to-arm difference in how many cited the text counts those seats rather than measuring the text — a confound that often explains a separation more simply than the wording does, and one the plant is what makes visible. Such a separation is not attributable to the text: the run returns a null and says what that null bounds. **It reaches only a run whose arms both carry the plant** — a confirm's or a substitution's, never a screen's, whose ablated arm has no plant to read and whose zero is structural rather than habit. **In a substitution, a plant found redundant after the fact bounds its null the same way**: both arms could reach the behaviour without the wording, so the agreement measures the plant rather than the text, and the run says what that bounds. That is this reading applied to a redundant plant rather than a disposition of its own, and it is stated of a substitution alone — **not because a confirm is immune, but because it is worse there**, where such a plant instead satisfies the deletion licence on text that was live. The control certifies the run, not the item — an item no seat treated as a live candidate is uninformative rather than null, and is rebuilt.

**And the arms have to be two**, which means no seat may load the repository the text lives in — reconstructing the material as prompt text is one way and the isolated trees above are another: a seat dispatched inside that repository loads the real thing, both arms become the same arm, and the plant is still cited — so the run reads valid and everything comes back kept. That collapse is a failure this control cannot see, as a redundant plant is.

**Where a plant must be scored, or the run would license removing the text under test: `../references/licensing-a-deletion.md`** — the record search that ends a run before it is dispatched, what counts as a seat having cited text, and which disposition a scored run reaches. Load it whenever you score a plant, and always where a deletion is the point.

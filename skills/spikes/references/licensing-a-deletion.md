# Scoring a cold-seat A/B, and licensing a deletion from one

**Loaded when** you are scoring a cold-seat A/B's planted control, or the run's output would be the removal of the text under test.

**What counts as a citation, without which nothing below can be applied: a decline reasoned from something other than the text under test is not one** — most often the absence of a positive trigger, even where its content coincides with the text's. A seat attributing the effect *to the text* — *"its entry explicitly excludes push-rejection recovery"* — is citing, in whichever arm. Score both arms by the same reading, and say who scored: a run scored by the dispatching session is not blind to arm.

**Search the record before dispatching anything, because a hit ends it.** One place the text is already leaned on — an entry, a review, a session note — costs one search to find, where the run below costs six seats, and it is the stronger witness: the rule below keeps on one cold seat working a docket somebody wrote for it, where a session that leaned on the text in its own work owed nothing to a docket. **Such a hit keeps the text, and the run is not dispatched.** Two conditions, without which a record that discusses everything would keep everything: the session **used** the text — gave it as its reason for what it did — where a document discussing the text mentions it and is not one; and it used **the text as it now reads**, a citation of wording since replaced being a citation of something else.

**Deletion requires a run whose arms differ in that text alone, in which no seat, in either arm, cited the text or its substance, and which ran at least three seats an arm** — the width the [run this rule comes from](https://github.com/Grimblaz-and-Friends/tradecraft/issues/260#issuecomment-5503370780) separated at, and which that record notes is contested from above rather than below. **Anything else keeps or is `unresolved`, and the arm decides which.** A citation from the arm **holding** the text is a keep, one seat being enough. Where the only citations came from the arm the text was **removed** from, the run is **`unresolved`**: the text stays, on the same asymmetry below, but nothing was measured about it, so it may not be recorded as tested-and-kept. **A screen licenses no deletion**: where the arms differ by a whole class the result is attributable to the class, and a per-target confirm has to follow before any one sentence goes. A deletion licensed by a void run is licensed by nothing.

The asymmetry is the cost asymmetry. Three seats an arm can show that text nobody reaches for is not carrying its situation; they cannot show that text one seat leaned on is safe to remove. Keeping inert text costs characters. Deleting live text costs a session routed where the text existed to stop it — which no guard catches, and which surfaces as somebody's bad change months later.

**An `unresolved` run says the instrument was blind, not that the text is live.** A seat reasoning the substance of text it could not see rebuilt it from what remained — the cell's name, the summary sentence above it, an always-on surface naming the destination. **For the licence that is terminal**: such a run fails the rule above by construction, and no further arm rescues it, a run removing a second thing alongside the text no longer being one whose arms differ in that text alone. **For the measurement it is not.** A further arm that removes the reconstruction source alongside the text leaves a seat nothing to rebuild from, and says which it was: seats that stop giving the substance show the source was carrying it, seats that still give it show nothing in the material was and it comes from the model. **Either result is a measurement and neither is a licence** — a deletion still needs the clean run the rule above describes.

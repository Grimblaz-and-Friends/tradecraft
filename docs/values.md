# Values — the ranking function

> **In plain terms:** when the evidence can't say whether work is worth doing — prevention, tooling, craft, the things whose value never shows up in a measurement — this ranking is what the judgment is made against instead. It is the owner's document: sessions argue with it freely, but only the owner amends it.

**Purpose:** give the unmeasurable half of every worth-it judgment an explicit declaration to be judged against, so work whose value resists measurement is funded deliberately rather than lost to the measurable by default. **Audience:** the owner when amending it; any session weighing whether work is worth doing when the evidence runs out, filing an item whose case rests on one, or reading the board at rest. **Success:** worth-it judgments on unmeasurable work cite a numbered value rather than vibes, an open item whose case rests on unmeasurable value carries that value where its case is made, and the shipped portfolio does not drift toward only the short-horizon and measurable.

**Status: adopted, and binding.** Declared alongside [`north-star/flow.md`](north-star/flow.md) as reference that bound nothing, and adopted through normal ceremony on [#215](https://github.com/Grimblaz-and-Friends/tradecraft/issues/215) — this repository's doctrine now points here, and a worth-it judgment whose evidence runs out is argued against the ranking below, by number. Amendment is the owner's alone.

## Why this exists

Economic machinery sharpens cost estimates for all work but value estimates only for *measurable* value. Without a counterweight, prevention, compounding work, and craft lose every tie, and the portfolio drifts toward the short-horizon and measurable — one locally rational decision at a time. This document is the counterweight: an explicit, owner-declared ranking that worth-it judgments are made against when measurement can't answer.

## How it is used

- **At any gate**, when the worth-it question outruns the evidence, the answer is argued from this ranking — by number, so the reasoning is checkable.
- **Order resolves conflict.** When two values collide, the higher one wins. A decision that sacrifices a higher value for a lower one is wrong even if locally attractive. Precedence operates within a single decision; it never drains lanes — allocation exists precisely so lower-ranked values stay funded, and the ranking informs lane sizes rather than overriding lane boundaries.
- **Allocation, not per-item ROI.** Work whose value resists measurement is funded as a standing share of capacity per value, and competes within that lane — never head-to-head against measurable-value work.
- **The re-ask still applies**, but asks "is this still serving its declared value, within its allocation?" — not "have metrics proven it?"
- **Both-ways guard.** No demanding measurement from values-funded work; no dressing values-funded work in proxy metrics. A claim names the value it serves, or it isn't one.
- **Recognition is what makes that guard fireable.** A claim carries its value because someone is arguing worth as it is read; an open item is read at rest, by a sweep nobody is present to answer [D-225]. **So an open item whose case for being picked up rests on unmeasurable value names that value too**, by number, where its case is made. Absence of a name means untagged, never *measurable*: a sweep gives an untagged item what it would have given it anyway, and reading absence as a measurability claim turns this guard backwards onto the work it exists to protect.
- **Tripwire:** periodically look at what actually shipped. If it's all short-horizon and measurable, the drift is happening regardless of how each call felt.
- **Amendment is the owner's**, with the same ceremony as any rule change. Sessions argue against it freely; they don't reinterpret it.

## The ranking

1. **Trustworthiness.** What ships does what it claims, and its state is reported honestly — failures, skips, and uncertainty included. Nothing below justifies shading this. Funds: verification depth, security, tail-risk work.
2. **Compounding.** Each change makes future changes cheaper, safer, or better-informed. The practice's reason to exist. Funds: mechanisms over prose, tooling, evals, decision records, prevention.
3. **Owner attention.** The scarcest input. Spend it only on genuine forks, and arrive prepared — argued options, a recommendation. Funds: anything that converts a recurring ask into a standing rule or mechanism.
4. **Evidence.** Settle by running, not arguing, wherever possible. Funds: spikes, repros, measures, canaries — the cost of making questions executable.
5. **Craft.** Work a future reader can trust and extend without archaeology — clear intent, right home, no cleverness tax. Funds: refactoring, legibility, simplification.

Ordering rationale, briefly: trust is load-bearing for everything (an untrustworthy practice compounds errors); compounding is the mission; attention is the binding constraint; evidence and craft are how the first three stay cheap. Ties within a lane go to the option that serves the higher neighboring value.

## What this is not

Not a metrics dashboard, not a mission statement, not immutable. It is the thing the unmeasurable half of every worth-it call is judged against — and it only works if it stays short enough to actually be held in mind.

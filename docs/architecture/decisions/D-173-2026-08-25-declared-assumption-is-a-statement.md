# D-173: A declared assumption is a statement, and two dispatch checks stop an instrument reporting a result it did not measure

**Status:** Accepted 2026-08-25 (PR #173)

## Context

The two instruments this practice added in slice 1 — the experience session ([D-131](D-131-2026-08-23-experience-session.md)) and the graduated spike ([D-132](D-132-2026-08-23-spikes-graduate.md)) — both ran on unrelated changes for the first time in this design's first full run, PRs #135 and #136, and both **paid**: the session found four things a five-seat panel did not, three of them before the panel convened. The [field data](https://github.com/Grimblaz-and-Friends/tradecraft/issues/122#issuecomment-5390224102) records that, and records that each was nearly fooled the same way — the run quietly measuring something other than what it was pointed at. Neither failure is a defect in the instrument's shape; both are in its **dispatch**, which is why neither remedy is a new piece. Neither was the experience session's *first* run at all: D-131 records one on the built cell of PR #131 itself, before that change's review, which found seven things wrong with it and two contradictions — so the instrument's record behind *"both paid"* is longer than this paragraph's own framing gives it.

**Both incidents are one dispatcher on one run**, and that base is stated plainly because a later session weighing whether to supersede this entry needs it. Both were self-caught, and self-caught late: one by the dispatcher recognising a sentence it had itself edited, one by reading results that should have differed and did not.

Riding with them is [#150](https://github.com/Grimblaz-and-Friends/tradecraft/issues/150), whose ruling had no vehicle of its own — it needed this cell opened, and opening a cell twice for one paragraph is the cost the batch avoids.

### The gap #150 records

The experience session's **arbitration** duty, deleted from D-131 after its review closed, did two things: it named a falsifier for an asserted behaviour, and it **booked the next real occasion** as that falsifier's live test. `skills/spikes` inherited the naming — an abandoned spike's premise enters what you were writing *"as a declared assumption with the falsifier that would settle it"* — and nothing inherited the booking. A grep during slice 1's review found no surviving surface that returns to a declared assumption; the same query on this change's base confirms it: `grep -rn -i "declared assumption\|assumption\|revisit\|return visit\|booked\|booking" skills/ AGENTS.md` at `92ff879` returns exactly one line, `skills/spikes/SKILL.md` at `92ff879`, line 28.

The owner was given three argued options — a successor owns the booking; a declared assumption is a statement, never a promise; or book only what a review sustains — and ruled the second on 2026-08-23.

## Decision

**1. A declared assumption is a statement, never a promise.** The falsifier stays required, because it is what makes the assumption honest and any future test one dispatch away if anyone ever cares. No one owes a return visit. **Reopen condition, fixed at the ruling:** an incident where work rested on a declared assumption that was false while its falsifier sat unused — on which the shape to argue first is a successor owning the booking.

**2. The ruling ships no rule sentence, and this is the part worth recording.** The vehicle in #150's affirmation was conditional: at most one sentence in `skills/spikes`, "if its artifact finds current prose leaves a reader expecting a return visit (the no-armor rule may well say it does not)" — the parenthetical being the owner's own steer toward the outcome taken here. It does not, and the reasoning is what a later session needs, not the verdict:

- **The default under uncertainty is already the ruled behaviour.** A session unsure whether it owes a return visit resolves that by not making one — there is no register, and no occasion to schedule against. The asymmetry is the whole argument: had a successor owning the booking been ruled, a sentence would have been **mandatory**, because the default would then be wrong. A ruling that nothing is owed is the one ruling silence can discharge.
- **The cell already answers the question that would produce the misreading.** The case for a sentence is not that a reader misparses a rule; it is that a recorded falsifier looks instrumental — why write down what would prove you wrong, if nobody will run it — so a session might *park* a premise rather than assert it, which is a rule silently repricing an action. But `:32` already locates the accountability moment at approval, now: the report is *"the only thing whoever approves the work can weigh against a premise still declared open."* The instrumental reading requires ignoring a sentence already there.
- **There is no incident.** #150's evidence is that nothing *inherited* the booking, found by grep — not a session going wrong under `:28`. An agent-proposed rule needs an incident from real work; an owner-stated one does not, and this ruling is the owner's, so a sentence was available to him. He declined it on the argument above. What a session may warrant unaided is making the record findable, which governs nobody.
- **The failure is cheap and detectable in one direction and neither in the other.** No sentence and wrong → a session hesitates and then does the right thing anyway. A sentence and wrong → permanent prose whose content is that nothing happens, invisible afterwards, paid by every reader.

**3. The entry is cited from `skills/spikes/SKILL.md:28` as `[D-173]`, and the citation's cost is accepted rather than argued away.** The party most likely to undo this ruling is a session revising that line, and `authoring` obliges a reviser to read a cited entry first. **The cost:** before this change `spikes` carried no decision citation — including [D-80](D-80-2026-08-19-spikes.md) and [D-132](D-132-2026-08-23-spikes-graduate.md), which wrote the cell — as do `authoring`, `charter`, `experience-session`, `filing` and `persist-changes`; only `adversarial-review` and `engagement` cite at all, six cells of eight carrying nothing (`for f in $(git ls-tree -r --name-only 92ff879 skills/ | grep 'SKILL.md$'); do echo "$(git show 92ff879:$f | grep -o '\[D-[0-9]\+\]' | wc -l) $f"; done`). A first-and-only marker in this cell, on a line whose wording this entry did not change, **inverts the signal**: a reader may infer that line is the one with reasoning behind it, when every line has. Backfilling D-80 and D-132 would answer it and is citation bookkeeping, which this repo's records-are-exhaust rule refuses as a change of its own.

**4. `skills/experience-session` gains a dispatcher check, not a fourth piece.** The first paragraph of *Running one* already names what the consumer receives — **the material as this change leaves it** — and the amendment makes that checked rather than assumed, naming the two ways the first run got it wrong at once: an isolation created from the default branch, and a job stated as of a date the change postdates. The reason is stated as the failure's own signature: *a note reporting friction the change already fixed reads exactly like one reporting friction that is live* — which is why the incident survived to be caught by recognition rather than by anything structural.

**Placement is the first paragraph rather than *Isolate the run***, though the incident's proximate cause was an isolation flag. The failure is about **what the consumer receives**, which is the concept that paragraph owns and names in those exact words; the mechanism that delivered the wrong text is incidental, and a check sited at the mechanism would be scoped to it. **What no placement fixes is the check's own object.** The rule's object is the tree; the stale-date cause named beside it is a property of the job's framing, which no tree check can see — so the sentence closes one of the two causes it names and puts a dispatcher on notice about the other. That is deliberate under `authoring`'s no-armor rule and it is a real limit, recorded here rather than claimed shut.

**5. `skills/spikes` gains the docket's actor condition.** Where the rule under test opens only for a particular actor, the docket has to put a seat in that position — *a docket no seat can enter through the rule's own door tests the rule's absence, and both arms then agree for the reason that the rule never fired.* It goes on the existing docket property rather than becoming a fifth, because it is a property of a realistic docket rather than a new one: a docket that cannot exercise the rule is not realistic.

## Rejected

- **A sentence in `skills/spikes` stating that the declaration is terminal.** Drafted concretely so it could be weighed against the alternative rather than in the abstract — *"A declared assumption is a statement, not a promise: nothing returns to it"* — and put to the owner with the argument for it, including the instrumental-falsifier reading and #152's precedent that absent content cannot be fixed by deletion. Declined for Decision 2's reasons. **The #152 analogy breaks on one joint:** there, a session held an object and had to act on it with no bar for the act; here there is no act, and absent guidance about something you do not do is not a hole.
- **The entry alone, with no mark in the cell.** This was the drafting session's first recommendation, and it was wrong on findability: it leaves the ruling reachable only by searching the log, and the party who would unknowingly undo it is looking at `:28`, not at the log. Corrected before affirmation.
- **A successor owning the booking, and booking only what a review sustains.** Both were put to the owner as argued options on #150 and both declined. The first is a standing obligation on every declared assumption forever, and the occasion is often unknowable at declaration time; the second adds a ruling obligation to the review stage and needs a load-bearing-enough discrimination with no instrument behind it. The first is the shape to argue on the reopen condition.
- **A register of open assumptions.** A list that would demand maintenance after its append, which records-are-exhaust forbids.
- **A fourth piece, a template, a field list, or a verification stage in `experience-session`.** D-131 names a fourth piece as the counter-bureaucracy failure the instrument exists to refuse; the remedy here is a line where the dispatch is described, which is what the field data itself proposed.
- **A cold-seat A/B on either new wording.** Each states a check the dispatcher performs rather than a judgment a reader interprets, so the reading is not genuinely in doubt and `skills/spikes`' own trigger does not fire. The use side is covered by the experience session this change buys.
- **Backfilling `[D-80]` and `[D-132]` onto the cell they wrote.** It would answer Decision 3's stated cost and is out of the affirmed boundary; a pull request whose content is record bookkeeping is this repo's own tripwire.

## Deferred, with the evidence that would reopen them

- **The ruling's discharge-by-silence is observed once, n=1.** A cold consumer holding an abandoned check, asked what happened next to what it left open, reached the ruled fate from the cell alone — *"a declared debt, not a gate"* — and rested it on `:32`'s report clause, which is the sentence Decision 2's argument turns on. One consumer, one job. **Reopen on:** a session that treats a return visit to a declared assumption as **owed** — booking, scheduling, or reporting one as an obligation rather than by its own choice — at which point the sentence rejected above ships, and the argument in Decision 2 is what was wrong. The qualifier is load-bearing and is the one the trigger first went out without: the same consumer that declined the obligation went on to book a return visit **voluntarily**, as an acceptance criterion of its own work, which is the ruled shape working rather than evidence against it.
- **The citation's inverted signal is accepted on an argument, not a measurement.** **Reopen on:** a session treating `:28` as the cell's only reasoned line, or citing its presence as evidence about a neighbouring line.
- **Nothing validates the marker, and the resolvable form is barred.** No guard reads a `[D-N]` in the shipped zone: `check_decision_index` compares only an index row's link target, `check_entry_references` reads only files under the log, and a marker citing an entry that does not exist passes `lint` clean. Writing it as a resolvable link instead fires the zone wall, since it would reach `docs/`. So the citation is unverifiable by construction, and the experience session observed the consequence — the marker reached all three consumer trees resolving to nothing, which is also what it does for anyone who has only the shipped cell. **Reopen on:** a `[D-N]` marker found dangling, or a second cell acquiring one.
- **Both dispatch checks were wordings when this entry was drafted, and the run has since answered both.** The experience session this change buys dispatched three cold consumers: one verified its consumer's tree before dispatching, and one caught its own docket failing to seat the licensed actor — *"only because that sentence is in the skill."* **Reopen on:** any later dispatch against a tree it did not verify, or any A/B whose arms cannot enter the rule's own door, *with the amended cells in front of it*.
- **Neither check is enforceable by anything but a reader.** No guard sees an isolation created from the wrong base, and none reads a docket. That is deliberate — a guard here would need to know which tree is *the change's*, which the dispatcher knows and CI does not. **Reopen on:** a second dispatch against the wrong tree after this change lands, which would show the reader-level check does not hold.
- **#150's gap has a sibling this entry does not reach.** [#161](https://github.com/Grimblaz-and-Friends/tradecraft/issues/161) asks what obliges a session to declare an untested premise **at all**, in terms of what the artifact carries; this entry answers only what is owed once one is declared. They are compatible, and if #161 lands an obligation to declare, the volume of declared assumptions rises while nothing returns to any of them — which is the condition under which the reopen trigger in Decision 1 becomes likelier rather than less.

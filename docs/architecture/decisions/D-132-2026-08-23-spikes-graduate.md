# D-132: Spikes graduate to their own cell, and the trigger is keyed to what a session can consult

**Status:** Accepted 2026-08-23 (PR #132)

## Context

[D-80](D-80-2026-08-19-spikes.md) landed spikes as a reference file with an artifact-keyed trigger, and declined depth explicitly on the ground that the practice had **zero runs**. [D-104](D-104-2026-08-22-engagement-cell.md) moved the file to `engagement` unchanged and recorded a graduation condition at `:36`, so a later session would not have to re-derive it: *"if the trigger broadens past the artifact — a spike serving a review finding, an implementation question, a doctrine proposal — it clears the independent-trigger bar and becomes its own cell."*

Both conditions moved. Runs exist — three were reported on [#92](https://github.com/Grimblaz-and-Friends/tradecraft/issues/92) on 2026-08-21 and are named in [D-99](D-99-2026-08-21-dispatch-prompt-caching.md)'s Evidence line — and the [#115 spike](https://github.com/Grimblaz-and-Friends/tradecraft/issues/115#issuecomment-5384143581) is the run that demonstrated the reframe this entry rests on. It **served** a disputed issue thesis, a review-routed finding's exhibit, and a candidate rule wording — falsifying the first, non-reproducing the second, withdrawing the third on its own evidence — while the surface asserting them was a pre-implementation artifact, so it fired inside the unbroadened trigger and its own report says so. D-104:36 words its condition about what a spike *serves*, and on that wording it is met.

The reframe is **governing prose is a mechanism whose executor is a reader**: a wording no cold session has worked under is, under the corrected limb below, behavior no run you can consult has exercised. Stated in the trigger's pre-correction words it would read *a mechanism nobody has executed* — the formulation this entry removes as defective, and the reframe survives its removal intact.

Both frozen entries are superseded by being read, per the decisions rule. Nothing in either is edited.

## Decision

**A sixth cell, `skills/spikes/`.** The trigger binds no surface: it fires on a load-bearing premise wherever asserted — an artifact's claim, a review thesis still disputed after a round, a candidate rule wording, a question arising while building.

**Its own cell rather than a broadened reference where it sat, and the argument is mechanical rather than aesthetic.** The broadening exists for sessions that are not writing an artifact. `tools/lint.py` forbids one skill referencing another skill **by path**, so `adversarial-review` cannot point a disputing seat at `engagement/references/spikes.md` in any path form. That is not machine-foreclosure: the lint exempts full web URLs by design and leaves name-form coupling to review, so a URL pointer was lawful — it is simply not a handle a cell can be built on. **The new cell is equally path-unreachable from `adversarial-review`**, so the graduation buys no path reachability at all. What it buys is a frontmatter description, which is the only handle a routing session actually has, and left in place the change would have been lawful and effectively inert. `engagement` keeps one sentence naming the move and restating none of the trigger's conditions, since a restatement is the drift `authoring` forbids and the failure the plain brief's own duplication already cost this repo once. It names the move without naming the cell, following `filing`'s precedent for the pre-implementation artifact.

**The name is the owner's, taken 2026-08-23:** `spikes`, the word the record already uses. The live alternative was a plainer name (`premise-testing`), rejected for costing the vocabulary the record already uses throughout.

### The four wording changes the spike forced

Each is recorded with the seat result behind it, because none is in the issue and a later session would otherwise read them as drafting preference. The run is [reported on #124](https://github.com/Grimblaz-and-Friends/tradecraft/issues/124#issuecomment-5387189398): ten cold seats over five wordings, against a docket growing to nine situations, seven of them in every arm. **It is a sequence, not a single-variable A/B** — each arm carries the previous arm's fixes, and every arm after B moves more than one clause — so it does not meet the fourth property the cell states, and the exemplar the cell links ([#115](https://github.com/Grimblaz-and-Friends/tradecraft/issues/115#issuecomment-5384143581), two arms differing only in one sentence) is what does. The report's own limits section says the same.

- **`a mechanism nobody has executed` → `behavior no run you can consult has exercised`. This is a meaning change and also a correction.** A cold seat read the shipped words as *nobody, anywhere*, and observed that no session can evaluate that. [D-80:15] had already settled it the other way in as many words — *"the predicate is keyed to what the session can consult, not to what anyone has ever done"* — so the prose and its own recorded reason have disagreed since the day both landed. The review that landed it did not catch it, and no review since has had it in scope — #104's change to the file was a pure rename — so this is not a review-versus-cold-seat comparison; the first cold seat asked to *apply* the sentence caught it.
- **`material you cannot survey, not material you have not surveyed`.** All four seats in arms A and B — the two arms tested before the survey and exemption fixes, only the first of which was unbroadened — independently named `no enumeration you can consult covers` the file's most under-determined clause and split it the same two ways — material you cannot survey, versus material for which no pre-made index exists. Under the second, every exhaustiveness claim over shipped material fires a spike.
- **The consume exemption**, keyed to nothing resting on the answer. The broadening as the issue words it fired on a thirty-second regex check in both seats that saw it, both calling the ceremony oversized — the counter-bureaucracy [#122](https://github.com/Grimblaz-and-Friends/tradecraft/issues/122) names as failure mode one. **The first fix was wrong and is recorded as such:** keyed to cheapness, the exemption swallows the paradigm case, since a session can always just go build the guard. Rekeying it to the handoff separates the trivial check from the acceptance criterion that rests on the same kind of fact.
- **The reframe defers to the load-bearing condition** instead of asserting an identity. *A wording no cold session has ever worked under* is true of every newly drafted sentence, so read literally the reframe fires on all prose changes — which contradicts the file's own *"a phase that always fires has stopped being a decision."* Both arm-D seats reached that reading unprompted; the identity form was in front of six seats across arms B, C and D, and two are recorded reaching it.

Two smaller changes ride with them: the exclusion leads with its arbitration test and carries a tiebreaker (*what a reader will do under the wording is a spike; where the wording belongs is not*), after seats split on a placement dispute and one confirmed the sentence was what decided it; and `Running one` loses its own artifact-keying, which the broadening had otherwise stranded.

**Provenance compressed** to the rule's reason clause plus a link, per `authoring`'s state-the-rule-link-the-evidence standard. The reason survives; the migration's two paragraphs of history do not. It is a partial offset and not a balance: the trigger section gains 267 words and the compression returns 25. The growth is argued clause by clause above rather than netted out.

### The index, declined

**A spike commits nothing — no branch, no pull request — so a tracked index could only be appended to by the one instrument forbidden to write anything**, or by giving spikes the process the file says they need none of. That is the whole argument, and it is why the want behind the index is met differently: the report opens `# Spike report — <premise>`, so every run is findable by one search of the board, with no file to maintain. The want was real, and survives the correction above: D-80 declined depth for zero runs, and while runs existed within a day of it landing, they existed under no convention that made them findable **as a class** — D-99 names #92's three in prose, which no search reaches. That is what the report's opening line answers.

### The seam, and what is left untested

The boundary between an answer you consume and an answer something you write rests on is the least crisp joint in the trigger; four seats across two arms said so, and one moved back to *cannot tell* on the trivial-check case at the last round. It is an under-determination at the edge, not an over-fire — no seat in the last three arms ran ceremony on a trivial check. **The falsifier, so a later session settles it from one real occurrence rather than a sixth docket: a session that spends a spike's ceremony on a question nothing it writes rests on.** A sixth arm was declined rather than run, because five rounds of rewriting one paragraph on apparatus-facing evidence is the self-referential defect supply #122 warns against.

**A second joint is untested and has no falsifier, named here rather than left silent.** The consume exemption's worked account of what makes something a spike is affirmation-and-handoff — a property no non-artifact surface has — so a session mid-review reading it for the discriminating test may conclude its case is not the kind the file means. That is **under-fire**, the opposite direction from the falsifier above, and it is routed to [#125](https://github.com/Grimblaz-and-Friends/tradecraft/issues/125), which owns the review surface. It is not fixed here because the sentence is the run's most-iterated, its first fix was demonstrably wrong, and rewriting its tail would ship untested wording at the joint the run names least crisp.

**The `artifact` → `work` substitution at `A spike commits nothing` is a meaning change and is named as one.** *What it found is reviewed with the work that carries it* was true when every carrier was a pre-implementation artifact. Under the broadened trigger the carrier may be a review's final report, which is posted rather than reviewed — so the clause is narrowed to the carriers where it holds, and closing the exception is #125's.

**What carries no cold-seat evidence at all:** the arms were versions of the old reference file, which has no frontmatter and no cold-seat A/B section. The `Cold-seat A/B` section and the routing description — the two pieces the graduation's mechanism actually rests on — were in front of no seat, while the trigger paragraphs carry five rounds. Nor was `skills/engagement/SKILL.md`.

The docket is nine constructed situations; every seat was handed the trigger and asked to apply it, which measures how a wording sorts situations against each other and inflates the absolute rate at which any trigger fires, equally in both arms. No absolute firing rate is claimed anywhere.

## Rejected

- **Broadening the trigger where the file sat.** The cheapest change and the one the issue left open. It fails on discoverability, above: a reference inside `engagement` is reachable from the surfaces the broadening serves only by URL or by name, neither of which is a handle a cell can be built on, so the change would ship and effectively never fire.
- **A spike index.** Above.
- **The issue's own wording of the broadening**, verbatim. It fires on trivial implementation checks, in both seats that received it.
- **A clause in `A spike commits nothing` for the prose case.** A seat observed that section reads as code-and-worktrees only and says nothing about a spike producing no tree. Declined as armor: *nothing committed, no branch, no pull request* is satisfied trivially by a cold-seat run, and the clause would defend against a reader who does not err.
- **A sixth arm** to close the consume boundary. Above.

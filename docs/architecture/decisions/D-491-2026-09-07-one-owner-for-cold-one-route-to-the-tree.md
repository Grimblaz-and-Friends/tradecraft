# D-491: The cold standard gets one owner and the isolated-tree procedure one route, and the copies they replace cost less than the pointers

**Status:** Accepted 2026-09-07 (PR #491)

## Context

Two symptoms of [#404](https://github.com/Grimblaz-and-Friends/tradecraft/issues/404), closed: [#375](https://github.com/Grimblaz-and-Friends/tradecraft/issues/375), four cells each stating what makes a seat cold with no two the same and no owner between them, and [#341](https://github.com/Grimblaz-and-Friends/tradecraft/issues/341), two instruments needing one isolated-tree procedure where only one carried it and the other could neither point nor copy. Both were unfixable before [D-437](D-437-2026-09-06-a-cell-may-point-and-a-circle-fails.md) made a pointer between cells lawful; the owner framed them together as the two symptoms whose fix deletes prose rather than adding it, and affirmed one brief governing both as a set.

**What the tree held at the base, `2c84f66`.** The four statements were `skills/engagement/references/cold-seat.md` at line 7, `skills/adversarial-review/references/roster.md` at 32, `skills/spikes/SKILL.md` at 42, and `skills/experience-session/SKILL.md` at 53. Only the first barred a seat that read an earlier draft; only the second named context inheritance and excluded the pull request's comment thread; only the third keyed on having read the argument; only the fourth barred telling the seat anything was under test. `skills/experience-session/references/isolation.md` carried the only written procedure for a history-free tree, and `skills/spikes/SKILL.md` carried the condition needing it — no repo history — with no route to it.

## Decision

**1. The `engagement` cell owns the cold standard, in `skills/engagement/references/cold-seat.md`.** It already held the only file in the practice whose subject is the cold seat, under its own `## Cold, here` heading, and the only statement carrying both halves — no conversation *and* no earlier draft — which the filing records as the half that gets lost. The file's load condition and the cell's depth-index entry widen from the artifact check to any cold dispatch. The operational half moves in from the review roster: a cold seat is always a fresh dispatch with context inheritance disabled, never a session that authored or discussed the material.

**2. Two other homes were live and both are rejected on the record.** `skills/adversarial-review/references/roster.md` carried the most operational statement, but inside a file about staffing a panel and seat-yield figures; widening that file's condition would make the roster the home of a standard three instruments that staff no panel must load. **The charter is refused on two independent grounds**, either sufficient, and this disposes of the shape [#341](https://github.com/Grimblaz-and-Friends/tradecraft/issues/341) deferred as live: `skills/authoring/references/cell-structure.md` scopes the always-on surface to a rule that must bind before any cell loads *rather than to one two cells share*, which is exactly this case; and the always-on row stood at 16,704 of 16,722, eighteen characters, so the text would need an admission the brief did not fund. **A new cell owning cold is refused on the same eighteen characters** — a cell's name and description join the always-on set in every adopting repository. **`engagement`'s own description and the charter's roster line are left unwidened, and that is prescribed rather than overlooked**: `cell-structure.md` widens a surface only *where no route holds*, and three pointers hold, all of them followed in use — so the ladder does not engage, and a description clause would cost an always-on admission against those same eighteen characters in every adopting repository.

**3. `experience-session` keeps the isolation procedure and `spikes` points at that cell.** Nothing moves; what was missing was the route. The file's load condition and the cell's depth-index entry widen to admit any instrument's run rather than this cell's alone. **They name no instrument**, deliberately: the first draft named two and leaked, for the reason under *Meaning changes* below. **Both edits are obliged rather than cosmetic.** The one-owner rule requires that a standard reach the reader it is taken from and that the mover name the route; and because `check_sideways_deps` still refuses a path into another cell's files, the pointer can only name the cell, so the destination's own text is what routes a stranger who arrives by name. **An earlier draft of this entry, of the artifact and of the pull request body said the depth index was the *only* such route, and that was false** — `skills/experience-session/SKILL.md:65` is a second, carrying its own load instruction and a fuller contents list, and it was left narrow until the review found it. Both routes are widened here. What the reach clause owes and nothing yet states — that a mover check the destination's **body** for narrower duplicate routes, not only its index — is filed as work rather than asserted here.

**4. What each cell keeps is what the core does not reach, and that is narrower than the artifact assumed.** Audited sentence by sentence against the core, `spikes`' whole statement was the core restated — a seat that has read the argument is one holding the conversation, and the session that proposed the wording is one that authored the material — so `spikes` keeps none of it. `experience-session` keeps one thing: that its consumer is not told anything is under test, the one cold seat that must not know it is an instrument. `adversarial-review` keeps the pull request comment thread as an exclusion the core does not supply, and its two carve-outs, the session note and a recorded finding being carried rather than withheld. **The narrowing was found while building, not while drafting**, and it is the reason the first pass overshot: text kept as an instrument's own increment was the shared sentence wearing local words.

**5. The brief's consequence claim is false, and it is recorded rather than engineered around.** The affirmed brief said *"the total prose a session can reach goes down rather than up."* The settled artifact made that criterion 5, falsifiable on the charter's reach row, which is the row measuring the practice's whole reachable prose. It **rose**. Before the review the figure was 235,444, +196 on the base's 235,248; after the review's fix batch it is **236,315, +1,067**. Three short definitional sentences were deleted; four name-form pointers, two widened load conditions and two widened depth-index entries cost more than they saved, and the review then required prose that cost more again. **Two of the pre-review figure's supports were wrong and the review corrected both**: the claim that every remaining candidate for cutting was routing prose the issues exist to add was false — 99 characters in `spikes` were a local restatement of the core, and deleting them is part of this batch — and the ask was put to the owner on that false ground. The residual is re-put on the measured figure rather than paid for by cutting: every addition the review required closes a consequence a consumer would experience, which is the bar a remedy adding weight to governing prose has to clear. **The general lesson, which the next symptom of #404 inherits:** collapsing a shared standard to one owner plus pointers buys correctness, not economy, whenever the copies are short — the pointer, the widened load condition and the widened index entry are a roughly fixed cost per pointing cell, and three sentences do not cover four of them.

**6. Individual reach rows rise far more than the total, and no guard rules on it.** Three rows rise sharply, which is the count the settled artifact gave and which an earlier draft of this section reduced to two: `spikes` 24,341 to 105,908, `adversarial-review` 52,216 to 109,816, and `experience-session` 23,750 to 81,467 — the last the largest proportional rise of the three at 3.4x, and absent from this entry until the review restored it. A row counts every cell it reaches whole. [D-437](D-437-2026-09-06-a-cell-may-point-and-a-circle-fails.md) decision 5 declined a ceiling here and that stands; a pointer is followed only by the reader who needs the standard, where four copies loaded unconditionally. Named because it is the figure a later reader notices first and would otherwise read as this change failing its own brief.

**7. Four cell bodies end over their ceilings** — `engagement` −119, `spikes` −88, `experience-session` −253, `adversarial-review` −9, measured after the review's fixes; before them it was three and `experience-session` had 81 characters spare. Nothing is cut and nothing is admitted: a cell body is measured against where it stood and passing it raises a pool item, which `tools/ceiling_filing.py` files after merge. **The review ruled that this is itself a risk rather than only bookkeeping** — the cheapest green way to clear an overage is to delete the pointer that caused it, which would revert #341, and nothing in the tree holds a pointer. That is filed as a cause.

## Meaning changes, named

`skills/authoring/references/revising.md` requires every one where amendments are recorded.

1. **Three cells stop defining cold and now depend on a fourth for it.** A session that loads only `spikes`, only `experience-session`, or only `adversarial-review` no longer finds what makes a seat cold in the cell it loaded, and must follow a pointer. That is the intended trade and it is a real loss of self-containment at the point of use.
2. **`spikes` no longer states anything about who may sit a fresh dispatch.** Its sentence about the seat that read the argument and the session that proposed the wording is gone entirely, not relocated — both halves were the core. A later session missing them there should follow the pointer rather than restore them.
3. **The roster's cold paragraph stops being a definition and becomes a delta.** Any rule keyed to it as the operational statement of coldness now reads against a paragraph that says what a *review* withholds beyond the standard.
4. **`skills/experience-session/references/isolation.md` is no longer an experience-session-only file.** Its load condition is written for any instrument's run, and a change to it now reaches a reader in `spikes`. **The first attempt at this widening named the two instruments outright and thereby leaked**: the file ships inside the arms of the very A/B it named, so a seat reading it learned what instrument it was sitting in. The experience session found it, the review found a second site in the cell's own index entry, and both now name no instrument.
5. **`skills/adversarial-review/references/dispatch.md:5` changed meaning without changing characters.** It promised *the full list of what a cold dispatch withholds* in the roster; this change moved the standard out of the roster, leaving a promise nothing kept. Repaired here.
6. **`skills/experience-session/references/running-instance.md:5` likewise.** Its *the reason sharpens here* compared against a sentence this change had deleted from `SKILL.md:53`; that sentence is restored, so the comparison stands again.

A bound on the seat's conduct rather than a statement of what makes it cold, so not #375's subject; the brief sends any other copied text to its own filing.
- **Extending the isolation procedure to a cold-seat A/B's two trees plus planted material.** #341 names the gap; that is *how isolation is done*, which the brief excludes.
- **A guard that a copy has not reappeared.** Worth wanting; the brief funded no code.
- **Whether the one-owner rule should have an exemption at all**, which #341 deferred. It has no carrier after this change: #341 closes here, and [#196](https://github.com/Grimblaz-and-Friends/tradecraft/issues/196) — which #341 named only as *the same shape from a different subject* — is closed `COMPLETED` and its own deferred list does not contain the question. Whoever wants it answered files it.

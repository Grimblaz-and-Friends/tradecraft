# Where the flow starts

**Loaded when** you are deciding where this cell's flow starts for the change in hand — whether it is mechanical work with no brief and no artifact to settle, or a change whose delivery is the truth of some text.

**Where the flow starts depends on the change.** Mechanical work has no brief and no artifact to settle, so it branches and then goes straight to *build*; the branch is never skipped, `main` refusing direct pushes; which work is mechanical *for the brief and the artifact* is the doctrine's Convergence bullet, which is loaded in every session already. Stated as a pointer rather than a copy because that exemption has one owner — and scoped, because it is not the only such list: what a change owes in sessions and declining lines is the `experience-session` cell's, whose list is narrower — a bump exempts only where it preserves behaviour — while the outflow's names the same work as this one and exempts only from the outflow an always-on edit owes. Stated at all because the flow chain in this cell's body opens on the brief, so a session doing a typo reaches this cell and meets a first step that does not apply to it. **And where what the change delivers is the truth of some text, a slice of build precedes the artifact**, as that same chain marks and the `engagement` cell states; the artifact stays where it was, settled before the first commit.
